# How to use the Open Graph Image Generator

## What is the Open Graph Image Generator?
The **Open Graph Image Generator** is a free, privacy-focused utility designed to help you design and export open graph images for social media sharing.

## What it does
Design OG images with custom colors, text, and gradients. All processing is done locally in your browser, meaning your data is never sent to a server.

## How to use it
1. Navigate to the [Open Graph Image Generator](/open-graph-generator) tool.
2. Follow the on-screen instructions and input your data.
3. Review the generated results in real-time.
4. Copy the output or download the generated files to use in your project.

## When to use it
You should use this tool when you need to quickly design og images with custom colors, text, and gradients. It is especially useful during the technical SEO auditing phase or when setting up a new website.

## Where to use it
This tool is perfect for web developers, SEO specialists, and content creators working on improving their technical SEO footprint. Simply run it directly in your browser on desktop, tablet, or mobile!
