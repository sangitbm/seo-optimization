## Tips for a Great Event Invitation QR Code

| Tip | Why It Matters |
|-----|---------------|
| Use a short, friendly event name | Guests recognize the QR code immediately |
| Add a "Call to Action" label on the link | Tells guests what to do — "RSVP Here", "View Details" |
| Test it before sharing | Always scan the QR code yourself first to confirm it works |
| Use a public link | The URL must be accessible without a login |
| Print at least 3cm x 3cm | Smaller QR codes may be hard to scan reliably |
