# How to use the Slug Generator

## What is the Slug Generator?
The **Slug Generator** is a free, privacy-focused utility designed to help you convert page titles and text into seo-friendly url slugs.

## What it does
Convert titles into clean, SEO-friendly URL slugs. All processing is done locally in your browser, meaning your data is never sent to a server.

## How to use it
1. Navigate to the [Slug Generator](/slug-generator) tool.
2. Follow the on-screen instructions and input your data.
3. Review the generated results in real-time.
4. Copy the output or download the generated files to use in your project.

## When to use it
You should use this tool when you need to quickly convert titles into clean, seo-friendly url slugs. It is especially useful during the technical SEO auditing phase or when setting up a new website.

## Where to use it
This tool is perfect for web developers, SEO specialists, and content creators working on improving their technical SEO footprint. Simply run it directly in your browser on desktop, tablet, or mobile!
