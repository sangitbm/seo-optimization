# How to use the Sitemap Generator

## What is the Sitemap Generator?
The **Sitemap Generator** is a free, privacy-focused utility designed to help you generate xml sitemaps for your website. add urls with priority, change frequency, and last modified date.

## What it does
Create XML sitemaps with priority and frequency settings. All processing is done locally in your browser, meaning your data is never sent to a server.

## How to use it
1. Navigate to the [Sitemap Generator](/sitemap-generator) tool.
2. Follow the on-screen instructions and input your data.
3. Review the generated results in real-time.
4. Copy the output or download the generated files to use in your project.

## When to use it
You should use this tool when you need to quickly create xml sitemaps with priority and frequency settings. It is especially useful during the technical SEO auditing phase or when setting up a new website.

## Where to use it
This tool is perfect for web developers, SEO specialists, and content creators working on improving their technical SEO footprint. Simply run it directly in your browser on desktop, tablet, or mobile!
