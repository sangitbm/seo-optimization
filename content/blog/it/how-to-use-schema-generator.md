# How to use the Schema Markup Generator

## What is the Schema Markup Generator?
The **Schema Markup Generator** is a free, privacy-focused utility designed to help you create structured data markup in json-ld format for google rich results.

## What it does
Create JSON-LD structured data for rich snippets. All processing is done locally in your browser, meaning your data is never sent to a server.

## How to use it
1. Navigate to the [Schema Markup Generator](/schema-generator) tool.
2. Follow the on-screen instructions and input your data.
3. Review the generated results in real-time.
4. Copy the output or download the generated files to use in your project.

## When to use it
You should use this tool when you need to quickly create json-ld structured data for rich snippets. It is especially useful during the technical SEO auditing phase or when setting up a new website.

## Where to use it
This tool is perfect for web developers, SEO specialists, and content creators working on improving their technical SEO footprint. Simply run it directly in your browser on desktop, tablet, or mobile!
